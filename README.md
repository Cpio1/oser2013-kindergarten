# Осер 2013
Локальный проект на Next.js 16, React 19, TypeScript и Tailwind CSS 4.

## Запуск
```sh
npm ci
npm run dev
```

## Проверки и публикация
```sh
npm run typecheck
npm run build
npm start
```
Production-сборка создаёт статический сайт в `out/`. Его можно размещать на статическом хостинге. Для Vercel используется обычный импорт Next.js-проекта. Сборка использует Webpack для совместимости с ограниченными средами.

## Данные и материалы
Все сведения редактируются в `lib/site-data.ts`. Незаданные контакты, документы и галерея автоматически скрываются. Изображения помещаются в `public/`, в данных указываются пути от корня: `/images/example.jpg`.
- `media.logo`: логотип; `media.hero`: main-page.
- `media.about`: main-page2; обязательно определить настоящий формат и установить `aboutType` в `image` либо `video`. HTML-страницу подключать нельзя.
- `gallery`: фотографии с осмысленными казахскими alt и при необходимости `position`, например `50% 30%`.
- `phone`: международный номер, `whatsapp`: международный номер для wa.me.
- `documentsUrl`: действующая ссылка на документы.
- `domain`: реальный домен с https, после заполнения включает canonical.
- `instagram`: только подтверждённый профиль. Предоставленный Reel хранится отдельно.

Локальные шрифты Nunito включают latin, cyrillic и cyrillic-ext; лицензия — `public/fonts/OFL.txt`. Все буквы ӘәҒғҚқҢңӨөҰұҮүҺһІі проверены по таблицам cmap в начертаниях 400, 600, 800, 900.

## Что требуется от заказчика
Логотип, фотографии main-page и main-page2, фотографии для галереи, телефон, WhatsApp, email, режим работы, подтверждённый Instagram-профиль, юридическое название, действующая ссылка на документы и реальный домен. Дополнительные занятия — только при наличии подтверждённой информации. «2013» считается частью названия, год основания не утверждается.

## Ограничение проверки
В текущей среде запрещены запуск Chrome и открытие локального порта. Проверки поведения и визуального оформления на целевых размерах, при увеличении текста и тёмной системной теме необходимо выполнить в браузере после запуска в обычной среде. Галерея готова в коде, но скрыта: реальные фотографии не предоставлены.
