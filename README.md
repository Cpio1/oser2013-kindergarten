# Осер 2013

Одностраничный сайт детского сада на Next.js 16, React 19, TypeScript и Tailwind CSS 4. Сборка — статический экспорт в `out/`.

## Запуск

```sh
npm ci
npm run dev          # разработка
npm run typecheck    # проверка типов
npm run lint         # ESLint
npm run build        # check:media + production-сборка (out/)
npm start            # локальный просмотр out/ на http://localhost:3000
```

На Vercel проект импортируется как обычный Next.js-проект.

## Структура

- `lib/site-data.ts` — **единственное место** для названия, адреса, групп, питания, ссылок, контактов и путей к медиа.
- `lib/links.ts` — формирование ссылок `tel:`, `wa.me` (с сообщением на казахском), карты и списка кнопок связи.
- `components/desktop/` — десктопная и планшетная компоновка разделов и навигации.
- `components/mobile/` — мобильная компоновка разделов и мобильное меню.
- `components/shared/` — общие элементы: шапка, подвал, заголовки разделов, иллюстрации, галерея, документы.
- `components/shared/Responsive.tsx` — показывает одну версию интерфейса: до гидратации неактивная скрыта CSS, после — удаляется из DOM.

Брейкпоинты в `em`, поэтому при увеличении шрифта в браузере сайт переключается на более компактную раскладку.

## Как заполнить данные

Пустые значения автоматически скрывают соответствующие элементы.

| Поле в `site-data.ts` | Что появится |
| --- | --- |
| `contacts.phone` (`+7 7xx xxx xx xx`) | кнопка звонка `tel:` |
| `contacts.whatsapp` | кнопка WhatsApp с готовым сообщением |
| `contacts.email`, `contacts.hours` | email и график работы в разделе «Байланыс» |
| `contacts.instagramProfile` | кнопка профиля (только подтверждённый аккаунт) |
| `links.documents` | раздел и пункт меню «Құжаттар» |
| `links.mapPlace` | точная карточка на карте вместо поиска по адресу |
| `legalName` | юридическое название в контактах и подвале |
| `domain` | canonical и `url` в структурированных данных |
| `media.logo` | логотип в шапке и подвале вместо знака-иллюстрации |
| `media.hero` (main-page) | фото на первом экране и Open Graph вместо иллюстрации |
| `media.about` (main-page2) | изображение (`kind: 'image'`) или видео (`kind: 'video'`) в «Біз туралы» |
| `gallery` | раздел и пункт меню «Галерея» (6 превью на компьютере, 4 на телефоне, остальное — в просмотре) |

Файлы кладутся в `public/` (например `public/images/main-page.png`), в данных указывается путь `/images/main-page.png` с точным регистром. Для каждого медиа нужно указать `width` и `height`. Для прозрачного PNG — `transparent: true`. У фото в галерее `position: '50% 30%'` задаёт кадрирование превью.

`npm run check:media` (запускается перед каждой сборкой) проверяет:
- файл существует с точным регистром имени (Vercel чувствителен к регистру);
- фактический тип файла совпадает с расширением;
- HTML-страница не подключена вместо изображения или видео.

## Ещё не предоставлено

Логотип, main-page, main-page2, фотографии для галереи, телефон, WhatsApp, email, график работы, подтверждённый Instagram-профиль, юридическое название, ссылка на документы, домен. «2013» — часть названия, год основания на сайте не утверждается.

Шрифт Nunito (OFL, `public/fonts/OFL.txt`) подключён локально. Все буквы Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі есть в каждом начертании (400/600/800/900).

### Подключённые фотографии

В `public/images/` находятся 24 фотографии и `main-page.jpeg` — эмблема садика.
Отдельных `logo` и `main-page2` в текущем наборе нет. Эмблема используется на
главном экране, в шапке и подвале без обрезки; исходный JPEG имеет белый фон.
Исходники сохранены, сайт использует WebP-копии из `public/images/optimized/`.
В `lib/site-data.ts` заданы точные пути, размеры и казахские описания.

Галерея показывает 4 превью до 640 px и 6 — начиная с 640 px. Превью и полный
просмотр используют `object-fit: contain`, чтобы сохранить все лица. Остальные
фотографии доступны через «Барлық фотолар»: кнопки, стрелки клавиатуры,
горизонтальные свайпы, Escape и возврат фокуса на исходную кнопку.
